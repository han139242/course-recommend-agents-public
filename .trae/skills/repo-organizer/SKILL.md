# Repo Organizer

## 目标

- 将仓库根目录保持“入口 + 配置”简洁
- 将资料、文档、图等放入明确的分类目录
- 保证不会把密码、Token、私钥等敏感信息提交到仓库

## 操作清单

1. 查看仓库根目录文件列表与 Git 状态
2. 按类型创建目录（示例：docs/、assets/、infra/、scripts/）
3. 使用 `git mv` 移动文件，避免丢失历史
4. 检查并更新 `.gitignore`，确保 `.env` 等敏感文件不会被提交
5. 如存在大文件（PDF/模型/数据集），优先用 Git LFS 管理并检查 `.gitattributes`
6. 最后执行 `git status` 确认变更干净且可提交

## 目录建议（可按项目调整）

- `book/`: 申报书、说明文档、参考资料（PDF/DOCX）
- `assets/`: 图片、图表、UI 资源
- `infra/`: 部署相关（docker-compose、k8s manifests）
- `scripts/`: 一次性脚本或运维脚本

## 注意事项

- 不要把写了真实密码的 `.env` 提交到 Git
- 不要在代码或日志里打印数据库密码/密钥
