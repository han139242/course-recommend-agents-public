# 软著手册撰写与截图指南

## 1. 目标

本项目软著材料建议按以下口径准备：

1. 源程序交存材料控制为 `60` 页，每页 `50` 行，总计 `3000` 行。
2. 用户手册或操作说明书控制在 `13` 到 `15` 页。
3. 手册中放置不少于 `7` 张截图，建议准备 `8` 到 `9` 张。
4. 手册中的功能描述必须和系统现有页面、按钮、数据流一致，不写代码里没有的功能。
5. 手册、截图、源代码中不要出现网址、外部站点名称、无关软件名称和无关图片。

## 2. 手册写作总原则

1. 全文统一使用一个软件名称，不要混用“平台”“助手”“智能体”“系统”多个主称呼。建议统一写成“知识点学习推荐系统”。
2. 写法尽量客观，少用“先进”“智能化升级”“大模型驱动一切”这类空泛表达。
3. 每段功能说明尽量采用固定句式：
   `用户执行什么操作 -> 系统如何响应 -> 页面显示什么结果 -> 对学习有什么作用`
4. 所有截图都要与正文段落紧邻，做到“先写功能，再放截图，再解释截图中的按钮和结果”。
5. 截图必须是完整功能区域，不要只截一小块弹窗，也不要把浏览器地址栏、收藏栏、聊天软件、任务栏一起带进去。

## 3. 手册页数分配

建议按 `14` 页控制，比较稳妥：

1. 第 `1` 页：封面、软件名称、版本号、编写目的。
2. 第 `2` 页：软件概述、目标用户、主要功能概览。
3. 第 `3` 页：运行环境、系统结构简述。
4. 第 `4-5` 页：知识图谱首页与图谱交互。
5. 第 `6-7` 页：知识点详情页、前置知识、后续可学、收藏与笔记。
6. 第 `8` 页：练习测验与答题反馈。
7. 第 `9-10` 页：推荐路径与路径管理。
8. 第 `11-12` 页：学习仪表盘、学习统计、能力画像。
9. 第 `13` 页：成长洞察、热力图、推荐结果汇总。
10. 第 `14` 页：系统特点总结与使用说明补充。

如果最终字数偏多，可以把第 `13-14` 页压缩为一页；如果偏少，可以在第 `3` 页补一张系统结构图或流程图。

## 4. 手册章节模板

下面这套结构可以直接照着写。

### 4.1 软件概述

可写内容：

1. 本系统面向课程学习场景，围绕知识图谱、学习路径推荐、学习进度跟踪和能力画像分析提供一体化功能。
2. 系统以知识点为核心组织学习内容，通过图谱方式展示课程之间的关联关系。
3. 用户可以在图谱中查看知识点、进入详情学习、完成练习、记录笔记，并在仪表盘中查看学习结果。

### 4.2 系统主要功能

建议拆成五个功能点：

1. 知识图谱浏览与检索。
2. 知识点详情学习与笔记记录。
3. 练习测验与掌握度更新。
4. 推荐路径展示与路径管理。
5. 学习仪表盘与能力画像分析。

### 4.3 典型操作流程

建议写成一条主线：

1. 用户进入系统首页查看知识图谱。
2. 用户通过点击或双击知识点查看关联节点。
3. 用户在右侧详情面板查看前置知识、后续可学和推荐路径。
4. 用户进入知识点详情页完成学习和答题。
5. 系统记录学习状态，并在仪表盘中展示统计结果和能力画像。

## 6. 每张图的正文怎么写

下面的句式可以直接改写后放进手册。

### 图1 正文参考

系统首页以知识图谱为主界面，顶部提供搜索和场景控制功能，左侧用于展示课程导航，中央区域用于显示知识点关系网络。用户可通过首页快速进入学习主线浏览状态。

### 图2 正文参考

用户双击知识点后，系统会按关联关系逐层展开相邻节点，并在画布中展示知识点之间的连接关系，便于观察前后知识衔接和课程间迁移关系。

### 图3 正文参考

当用户单击某个知识点时，右侧详情面板会同步展示该知识点的简介、掌握度、前置知识、后续可学内容以及推荐结果，用户可在此完成收藏和继续学习操作。

### 图4 正文参考

系统会根据当前知识点及学习状态生成推荐路径，并以卡片形式显示推荐原因和课程迁移方向，帮助用户形成连续的学习主线。

### 图5 正文参考

知识点详情页展示了知识点的基本信息、课程归属和学习状态，用户可以从图谱页面进入详情页开展进一步学习。

### 图6 正文参考

练习测验区域支持用户选择答案并提交，系统会记录答题结果，并用于后续掌握度分析和学习建议生成。

### 图7 正文参考

学习仪表盘对学习情况进行集中展示，包括总体进度、统计指标和推荐摘要，用于帮助用户快速了解当前学习状态。

### 图8 正文参考

能力画像区域通过多个维度展示用户的学习能力分布情况，并结合成长洞察提示用户关注薄弱方向和后续学习重点。

### 图9 正文参考

路径与热区结果页面集中展示推荐路径、学习热点和阶段性建议，便于用户进一步规划学习顺序与复习重点。

## 7. 去哪里截图

为了保证截图稳定，建议按下面顺序操作：

1. 先进入首页，截取图1。
2. 在首页双击一个核心知识点，截取图2。
3. 保持该知识点被选中，截取右侧详情面板，得到图3。
4. 继续使用同一知识点，截取推荐路径区域，得到图4。
5. 点击右侧 `开始学习`，进入知识点详情页，截取图5。
6. 在详情页下滑到练习题区域，选择一个选项后截取图6。
7. 登录后进入仪表盘，截取首屏得到图7。
8. 在仪表盘下滑到能力雷达和成长洞察区域，截取图8。
9. 继续下滑到推荐路径或热力图区域，截取图9。

## 8. 截图时必须注意

1. 不要截到浏览器地址栏。
2. 不要截到任务栏、聊天窗口、输入法候选框。
3. 不要出现外部网站名称、第三方服务名称、测试工具名称。
4. 不要出现与本项目无关的图片、图标或页面。
5. 截图要保证文字清晰，建议使用桌面端全屏浏览器，页面缩放保持 `100%`。
6. 每张图尽量保留完整模块边界，尤其是标题、按钮、数据区域要同时入镜。
7. 如果某张图要体现功能性，必须把可操作按钮一起截进去，例如 `适配视图`、`重置场景`、`收藏`、`开始学习`、`提交答案`。
