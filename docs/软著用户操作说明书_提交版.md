# 课程推荐智能体系统用户手册

注意：说明文档最少提供13页以上。

系统首页

进入系统后，首先进入系统首页。首页顶部显示系统名称、知识点搜索框、课程筛选框以及登录入口。页面左侧为学习导航区域，中间为知识图谱展示区域，右侧为节点详情区域，右下角为学习助手入口。用户可以在该页面完成知识检索、图谱浏览、节点展开、查看详情和进入学习分析等操作。

详情如下图所示：

[插入图片：图01 系统首页（图01_系统首页.png）]

注册

进入系统后，点击右上角“登录”按钮，在登录页面点击“已有账号？去注册”即可进入注册页面。在注册页面中，填写邮箱和密码后，点击“注册”按钮即可完成账号注册。注册成功后，系统会自动进入学习仪表盘页面。

详情如下图所示：

[插入图片：图02 用户注册（图02_用户注册.png）]

登录

进入系统后，点击右上角“登录”按钮即可进入登录页面。在登录页面中，输入邮箱和密码，点击“登录”按钮后即可进入系统。登录成功后，系统会自动同步当前用户的学习进度、收藏内容、学习笔记和学习路径数据。

详情如下图所示：

[插入图片：图03 用户登录（图03_用户登录.png）]

知识点搜索

在系统首页顶部搜索框中输入知识点名称、课程名称或主题关键词，系统会自动显示匹配的候选结果。点击某个候选项后，系统会在图谱中自动定位到对应知识点，并将视图聚焦到该知识点附近，方便用户快速进入学习。

详情如下图所示：

[插入图片：图04 知识点搜索（图04_知识点搜索.png）]

课程筛选

在系统首页顶部的课程筛选下拉框中，用户可以选择不同课程范围查看知识图谱内容。选择某一课程后，图谱会切换到当前课程视角，方便用户在指定课程内浏览知识点与关系结构。

详情如下图所示：

[插入图片：图05 课程筛选（图05_课程筛选.png）]

知识体系查看

在系统首页左侧“知识体系”区域中，系统支持按学科和按类型两种方式浏览知识内容。按学科模式下，可查看每门课程的知识点总数和已掌握数量；按类型模式下，可查看概念、方法、算法、应用、主题等分类情况。点击对应条目后，系统会自动在图谱中定位到相关知识内容。

详情如下图所示：

[插入图片：图06 知识体系查看（图06_知识体系查看.png）]

图谱节点展开

在图谱页面中，用户可通过左键点击知识点进行选中，通过双击知识点展开其关联节点，再次双击已展开节点时可收回对应节点。用户还可以使用鼠标滚轮进行缩放，并通过页面上的“适配视图”和“重置场景”按钮恢复图谱显示状态。

详情如下图所示：

[插入图片：图07 图谱节点展开（图07_图谱节点展开.png）]

右键学习菜单

在图谱中对某个知识点执行右键操作后，系统会弹出学习菜单。菜单中包括“加入学习路径”“收藏/取消收藏”“记笔记”“进入详细学习”“讲解这个知识点”“查看前置依赖链”“标记为已掌握”等功能项。用户可通过该菜单快速进入下一步操作。

详情如下图所示：

[插入图片：图08 右键学习菜单（图08_右键学习菜单.png）]

节点详情

在系统首页中点击某个知识点后，右侧会显示节点详情面板。该面板中可查看知识点名称、所属课程、知识类型、掌握度、知识说明、前置知识、后续可学知识以及相关知识。用户还可以在该区域进行收藏、记录笔记和进入详细学习等操作。

详情如下图所示：

[插入图片：图09 节点详情（图09_节点详情.png）]

收藏夹

在节点详情面板中点击收藏按钮后，当前知识点会被加入左侧“收藏夹”中。用户在收藏夹中点击某个知识点时，系统会自动重新定位到该知识点，方便后续集中复习和重点学习。

详情如下图所示：

[插入图片：图10 收藏夹（图10_收藏夹.png）]

学习笔记

在节点详情面板的“我的笔记”区域中，用户可以输入自己对当前知识点的理解、易错点和学习心得。点击“保存笔记”后，系统会保存当前内容，便于用户后续查看和整理个人学习记录。

详情如下图所示：

[插入图片：图11 学习笔记（图11_学习笔记.png）]

推荐路径

当用户选中某个知识点后，系统会自动生成推荐路径，并在左侧“学习路径”区域中显示推荐结果。用户可以点击“在图谱中显示”按钮将推荐路径高亮到图谱中，也可以点击“开始学习”按钮按顺序进入推荐学习流程。

详情如下图所示：

[插入图片：图12 推荐路径（图12_推荐路径.png）]

我的路径

在“学习路径”区域中，用户可以点击“新建”按钮创建自己的学习路径。通过图谱右键菜单将知识点加入路径后，可在该区域查看路径节点，并对节点进行上移、下移、移除、高亮和开始学习等操作，方便形成个人化学习主线。

详情如下图所示：

[插入图片：图13 我的路径（图13_我的路径.png）]

知识点详情页

在节点详情面板中点击“开始学习”，或者在右键菜单中点击“进入详细学习”，即可进入知识点详情页。在该页面中，用户可以查看知识点说明、前置知识、应用场景和推荐理由等内容，并从概览式浏览转入深度学习模式。

详情如下图所示：

[插入图片：图14 知识点详情页（图14_知识点详情页.png）]

练习测验

在知识点详情页中，系统会根据当前知识点加载对应练习题。用户选择题目答案后，点击“提交答案”按钮即可完成作答。提交后，系统会记录答题结果，并用于更新当前知识点的掌握度分析。

详情如下图所示：

[插入图片：图15 练习测验（图15_练习测验.png）]

学习讲解助手

系统提供学习讲解助手功能。用户可在系统首页右下角点击助手按钮，也可在知识点详情页中展开学习助手区域。输入问题或点击快捷提问按钮后，系统会围绕当前知识点给出知识讲解、学习建议和路径提示，并支持联动图谱执行相关操作。

详情如下图所示：

[插入图片：图16 学习讲解助手（图16_学习讲解助手.png）]

前沿扩展

在知识点详情页右侧，系统会显示“前沿扩展”区域。该区域可查看当前知识点的前沿摘要、关联主题以及代表性论文信息，帮助用户在掌握基础知识后继续了解更高层次的扩展内容。

详情如下图所示：

[插入图片：图17 前沿扩展（图17_前沿扩展.png）]

跨课程知识桥梁

对于具备跨课程迁移价值的知识点，系统会在页面中显示跨课程知识桥梁内容，展示来源课程和目标课程之间的知识迁移关系。用户可根据该内容理解不同课程之间的知识衔接方式，逐步建立完整的知识网络。

详情如下图所示：

[插入图片：图18 跨课程知识桥梁（图18_跨课程知识桥梁.png）]

学习仪表盘

登录成功后，用户可进入学习仪表盘页面。该页面展示当前学习概览，包括已追踪知识点数量、已激活能力维度数量、推荐动作数量以及整体掌握进度。用户可从该页面快速返回图谱继续学习，也可以继续查看更细致的分析内容。

详情如下图所示：

[插入图片：图19 学习仪表盘（图19_学习仪表盘.png）]

能力雷达

在学习仪表盘中，系统通过雷达图展示用户在数学基础、编程数据、机器学习、深度学习、视觉感知、语言知识、工程治理等维度上的综合表现。用户可通过该页面了解当前优势能力和待提升能力。

详情如下图所示：

[插入图片：图20 能力雷达（图20_能力雷达.png）]

知识热区

在学习仪表盘中，系统还提供知识热区展示区域。该区域通过热力矩阵展示不同知识点在不同领域中的关注情况和学习活跃程度，颜色越亮表示当前知识热度越高，便于用户查看当前学习重点。

在学习仪表盘中，系统会根据当前学习情况整理出推荐知识卡片。卡片中可查看知识点名称、学习进度、推荐原因和进入入口。用户点击对应卡片后，可直接进入相应知识点继续学习。

详情如下图所示：
