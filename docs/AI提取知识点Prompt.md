# AI 提取知识点 Prompt 模板

## 使用方法

1. 复制下面的 prompt
2. 把 `{课程名}` 和 `{文本内容}` 替换成实际内容
3. 发给 AI（推荐 Claude / DeepSeek / GPT-4）
4. 拿到 JSON 后保存为 `pipelines/txt2neo4j/config/curated_batches/course_xxx.json`
5. 如果一门课文本太长，分章节多次提取，最后合并

---

## Prompt 1：从课程文本提取知识点（每门课用一次）

```
你是一个人工智能教育领域的知识图谱构建专家。我会给你一门课程的教材/讲义文本，请你从中提取所有知识点，构建结构化的知识图谱数据。

## 课程信息
- 课程名称：{课程名}（例如：机器学习、深度学习、线性代数）

## 提取规则

### 知识点提取
1. **全面覆盖**：提取文本中出现的所有知识点，包括概念定义、算法名称、方法技术、定理公式、应用场景
2. **粒度适中**：
   - 太粗的不要（如"机器学习"只作为 topic，不要只写一个"机器学习"就完了）
   - 太细的不要（如"公式3.2"这种不要）
   - 好的粒度示例：梯度下降、反向传播、卷积运算、决策树、交叉验证、过拟合
3. **命名规范**：使用中文学术通用名称，简洁精确（如用"梯度下降"而非"梯度下降法优化策略"）
4. **entity_type 分类**（课程知识点必须是以下 8 种之一）：
   - `topic`：大的主题分类（如"监督学习"、"卷积神经网络"、"概率分布"），每门课 5-15 个
   - `concept`：基本概念、定义、原理（如"过拟合"、"特征值"、"条件概率"）
   - `method`：方法、技术、流程（如"交叉验证"、"反向传播"、"数据增强"）
   - `algorithm`：具体可实现的算法（如"随机森林"、"Adam优化器"、"A*搜索"）
   - `application`：实际应用场景（如"图像分类"、"机器翻译"、"推荐系统"）
   - `model`：具名模型、模型族或可作为学习对象的模型体系（如"BERT"、"GPT"、"扩散模型"）
   - `tool`：工程工具、数据库、推理服务或实验工具（如"vLLM"、"TensorRT"、"向量数据库"）
   - `framework`：开发框架、系统框架或方法论框架（如"PyTorch"、"LangChain"、"MLOps"）
   - 注意：`exercise` 只用于练习/题目型节点或非课程批次，不要写入课程知识点批次。
5. **description**：一句话描述，20-50字，说清楚"这个东西是什么/做什么用"

### 关系提取
1. **关系类型**（必须是以下6种之一）：
   - `SUBTOPIC_OF`：A 是 B 的子主题/组成部分（如"决策树" SUBTOPIC_OF "监督学习"）
   - `PREREQUISITE_OF`：理解 A 是学习 B 的前提（如"矩阵乘法" PREREQUISITE_OF "线性变换"）
   - `RELATED_TO`：A 和 B 有关联但没有层级/前置关系（如"精确率" RELATED_TO "召回率"）
   - `PART_OF`：A 是 B 的一个具体组成部分（如"卷积层" PART_OF "CNN"）
   - `USES`：A 使用了 B 的技术/原理（如"随机森林" USES "决策树"）
   - `APPLIES_TO`：A 被应用于 B 领域（如"CNN" APPLIES_TO "图像分类"）
2. **层次清晰**：用 SUBTOPIC_OF 构建 topic → concept/method → algorithm/application 的层级
3. **前置关系准确**：PREREQUISITE_OF 的方向是"A 是 B 的前置"，即先学 A 后学 B
4. **不要有孤立节点**：每个知识点至少有一条关系
5. **关系数量**：约为节点数量的 1.2-1.8 倍

### 数量要求
- 节点数：尽可能多地提取，目标 80-180 个（取决于课程内容量）
- 不要遗漏文本中提到的任何重要知识点

## 输出格式

严格输出以下 JSON，不要输出其他任何内容：

```json
{
  "source": "course_{课程英文缩写小写}",
  "course_title": "{课程中文名}",
  "nodes": [
    {
      "canonical_name": "知识点名称",
      "entity_type": "concept",
      "description": "一句话描述"
    }
  ],
  "relations": [
    ["源知识点名称", "目标知识点名称", "SUBTOPIC_OF"]
  ]
}
```

注意：
- relations 中的名称必须和 nodes 中的 canonical_name 完全一致
- 如果引用了本课程之外的知识点（如数学基础），也写入 nodes 中，后续我会去重
- JSON 必须合法，不要有注释、省略号或多余逗号

## 课程文本

以下是课程文本内容，请从中提取所有知识点：

---
{这里粘贴课程文本内容}
---
```

## Prompt 2：文本太长时，分章节提取

如果一门课的教材文本太长（超过 AI 上下文窗口），按章节拆分：

```
你是一个人工智能教育领域的知识图谱构建专家。我正在为课程"{课程名}"构建知识图谱。

这是第 {N} 章的内容："{章节名}"

请从中提取所有知识点和关系。

### 已提取的本课程知识点列表（前几章已有的，用于建立关系引用）：
{粘贴前几次提取的 canonical_name 列表}

### 提取规则
（同 Prompt 1 的规则部分，这里省略）

### 输出格式
输出 JSON，格式同上。如果本章知识点与前几章的知识点有关系（PREREQUISITE_OF、RELATED_TO等），也要写在 relations 里。

### 本章文本
---
{粘贴本章文本}
---
```

## Prompt 3：生成跨课程关系（所有课程提取完后使用一次）

```
你是一个人工智能专业课程体系设计专家。以下是 20 门课程的知识点名称列表。
请分析这些课程之间的知识关联，找出跨课程的前置关系和关联关系。

## 课程知识点列表

### 1. 高等数学
极限、导数、偏导数、链式法则、梯度、泰勒展开、定积分、多重积分、微分方程 ...

### 2. 线性代数
矩阵乘法、行列式、特征值分解、SVD、向量空间、线性变换、正交矩阵 ...

### 3. 概率论与数理统计
条件概率、贝叶斯定理、期望、方差、正态分布、极大似然估计、假设检验 ...

### 4. 机器学习
梯度下降、损失函数、正则化、SVM、决策树、随机森林、交叉验证、过拟合 ...

### 5. 深度学习
反向传播、卷积运算、池化、RNN、LSTM、注意力机制、Transformer、Batch Normalization ...

（... 列出所有课程的知识点名称 ...）

## 要求

1. 找出所有有意义的跨课程关系，重点关注：
   - 数学基础 → AI 课程的前置关系（如"偏导数"是"反向传播"的前置）
   - 数据结构 → 各课程的工具关系
   - 机器学习 → NLP/CV/RL 的前置关系
   - 深度学习 → 大模型的前置关系
2. 每门课至少输出 8-15 条跨课程关系
3. 关系类型只用：PREREQUISITE_OF、RELATED_TO、USES
4. 附上简短理由（一句话说明为什么有这个关系）

## 输出格式

```json
{
  "source": "cross_course_relations",
  "relations": [
    {
      "source_name": "偏导数",
      "source_course": "高等数学",
      "target_name": "反向传播",
      "target_course": "深度学习",
      "relation_type": "PREREQUISITE_OF",
      "reason": "反向传播的核心是用链式法则对各层参数求偏导"
    }
  ]
}
```
```

{可选：粘贴课程教学大纲}

## 完整工作流

```
第1步：准备文本
  ├── 收集每门课程的教材 PDF / 讲义 / 教学大纲
  ├── 转成纯文本
  └── 按课程分好（15门课 × 1-N 个文本文件）

第2步：逐课程提取（Prompt 1 或 Prompt 2）
  ├── 课程 1：高等数学 → course_calculus.json
  ├── 课程 2：线性代数 → course_linear_algebra.json
  ├── 课程 3：概率与统计 → course_probability.json
  ├── ...
  └── 课程 15：AI伦理 → course_ai_ethics.json
  
  每次提取后检查：
    ✓ JSON 格式是否合法
    ✓ 节点数是否够（目标80+）
    ✓ 有没有孤立节点
    ✓ 关系方向是否正确

第3步：补充遗漏（Prompt 4）
  └── 对节点数不够的课程做补充

第4步：生成跨课程关系（Prompt 3）
  └── 输入所有课程知识点名称列表 → cross_course_relations.json

第5步：导入 Neo4j
  ├── 先修复 curated_graph.py（支持 course_title 字段）
  ├── 修复现有节点的 chapter_title
  ├── 导入新课程 JSON
  └── 导入跨课程关系

第6步：验证
  ├── 前端图谱上检查课程颜色区分
  ├── 点击节点检查跨课程连接
  └── AI 助手中问"XXX和YYY有什么关系"验证图谱推理
```

## 注意事项

1. **一次不要喂太长文本**：如果超过 AI 上下文窗口，按章节拆分多次提取
2. **去重**：不同课程可能提取出相同的知识点（如"梯度下降"可能在高数和机器学习中都出现），导入时 Neo4j 的 MERGE 会自动去重
3. **关系方向**：PREREQUISITE_OF 最容易搞反，A PREREQUISITE_OF B 意思是"A是B的前置"，即先学A再学B
4. **JSON 校验**：AI 输出的 JSON 可能有格式错误（多余逗号等），导入前用 https://jsonlint.com 验证一下
5. **迭代改进**：第一轮不需要完美，先导入看效果，发现缺什么再补
