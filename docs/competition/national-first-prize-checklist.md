# 国家一等奖冲刺检查清单

## 现场运行

- [ ] 执行 `powershell -ExecutionPolicy Bypass -File scripts/start-demo.ps1`
- [ ] 浏览器打开 `http://127.0.0.1:8080/showcase`
- [ ] 确认 `http://127.0.0.1:8080/healthz` 返回 200
- [ ] 确认 `http://127.0.0.1:8080/readyz` 返回 200
- [ ] 打开 `http://127.0.0.1:8080/showcase` 作为答辩首页
- [ ] 准备备用截图：`artifacts/competition-smoke/`

## 演示主线

- [ ] 先讲评分对齐：创意、技术、应用、设计、效果
- [ ] 首页展示课程知识地图和学习导航
- [ ] 知识点详情展示练习测验、推荐路径、笔记和 AI 助教
- [ ] 学习总览展示掌握度、薄弱点和下一步学习
- [ ] 最后展示工程可靠性：测试、构建、Docker、健康检查

## 答辩重点

- [ ] 强调“跨课程边界”，不是单课程推荐
- [ ] 强调“知识图谱 + 学习画像 + AI 助教”的闭环
- [ ] 强调后端模块化、服务可观测、前端可复现
- [ ] 强调学生端体验：不用理解算法，也能知道下一步学什么
- [ ] 强调教研扩展：教师端/评测页可用于后台分析，但不干扰学生主流程

## 风险检查

- [ ] 不在学生主流程里讲论文、专利、算法评测
- [ ] 不临场解释端口混乱，统一说访问 `8080`
- [ ] 不依赖外网才能完成核心演示
- [ ] 不现场跑长耗时脚本，提前启动并保持服务
- [ ] 不展示空白图谱；如真实数据异常，使用已有截图和演示数据说明
