# A3 赛题功能实现说明

更新时间：2026-06-19

本文档记录围绕“中国软件杯 A3 基于大模型的个性化资源生成”赛题已完成的核心功能：对话式学生画像构建、多智能体个性化资源生成、资源反馈与学习效果评估、基于画像与反馈的下一步资源推荐、资源安全与防幻觉审查、资源包 Markdown 导出、演示 PPT 大纲生成。

## 功能 1：对话式学生画像构建

已实现一个独立的 `profile` 后端模块，用于把学生自然语言描述转化为结构化学习画像，并持久化为当前画像。

### 已完成能力

- 支持学生输入自然语言学习情况，例如专业基础、学习目标、已学内容、薄弱点、资源偏好。
- 自动抽取 6 个画像维度：
  - 知识基础
  - 学习目标
  - 学习进度
  - 认知风格
  - 易错点偏好
  - 资源偏好
- 每个维度包含维度值、置信度、证据文本，便于前端展示和后续资源生成引用。
- 支持保存确认后的画像，并保留画像版本记录。
- 支持读取当前学生画像，作为资源生成的个性化上下文。

### 后端接口

- `POST /api/profile/extract`：根据自然语言描述生成画像。
- `GET /api/profile/current`：读取当前学生画像。
- `PUT /api/profile/current`：保存确认后的画像。
- `POST /api/profile/refresh`：刷新当前画像读取结果。

### 数据表

新增迁移文件：`backend/migrations/000008_create_learning_profiles.sql`

- `student_learning_profiles`：存储学生当前画像摘要和原始输入。
- `student_profile_dimensions`：存储 6 个画像维度及证据。
- `student_profile_versions`：记录画像变更历史。

### 前端入口

新增页面：`frontend/src/views/ResourceCenterView.vue`

页面左侧为“对话式学生画像”区域，支持输入学习情况、生成画像、展示 6 维画像卡片、确认保存画像。

## 功能 2：多智能体个性化资源生成

已实现一个独立的 `resourcegen` 后端模块，用于基于学生画像、知识点信息和推荐路径生成多类型学习资源。

### 已完成能力

- 支持选择知识点名称、知识点 ID、课程名称、生成目标和资源类型。
- 生成过程以多智能体步骤显式展示：
  - `ProfileAnalystAgent`：读取学生画像、学习目标和资源偏好。
  - `CoursePlannerAgent`：结合知识图谱和推荐路径，确定知识点及学习顺序。
  - `ResourceWriterAgents`：协同生成多种学习资源。
  - `SafetyReviewerAgent`：检查资源格式、学习依据和内容安全。
- 支持生成以下资源类型：
  - 课程讲解文档
  - 知识点思维导图
  - 个性化练习题
  - 拓展阅读材料
  - 代码类实操案例
  - 多模态短视频讲解脚本（可选）
- 生成结果会进入学生资源库，页面可刷新查看历史资源。

### 后端接口

- `POST /api/resources/generate`：生成个性化资源包。
- `GET /api/resources/jobs/:jobId`：查询资源生成任务详情。
- `GET /api/resources`：查询当前学生资源库。
- `GET /api/resources/:resourceId`：查询单个资源详情。

### 数据表

新增迁移文件：`backend/migrations/000009_create_generated_resources.sql`

- `resource_generation_jobs`：记录一次资源生成任务。
- `resource_agent_steps`：记录多智能体协作步骤。
- `generated_resources`：存储生成后的资源内容。

### 前端入口

新增页面：`frontend/src/views/ResourceCenterView.vue`

页面右侧为“多智能体资源生成”区域，支持填写生成参数、勾选资源类型、查看智能体步骤进度、查看本次生成结果。页面侧栏提供资源库列表。

首页 `GraphHome.vue` 已新增“资源生成”入口，登录后可直接进入 `/resources`。

## 功能 3：资源反馈与学习效果评估

已在 `resourcegen` 模块中扩展资源反馈能力，用于收集学生对生成资源的学习效果反馈，并沉淀为后续推荐依据。

### 已完成能力

- 学生可对每个生成资源提交反馈：
  - 评分
  - 难度感知
  - 是否有帮助
  - 是否完成学习
  - 备注说明
- 系统会根据评分、难度、完成情况生成下一步行动建议。
- 支持同一学生对同一资源重复提交反馈，后一次会覆盖最新反馈。
- 反馈数据会被聚合为学习效果摘要，包括平均评分、完成次数、偏难次数等。

### 后端接口

- `POST /api/resources/:resourceId/feedback`：提交或更新某个资源的学习反馈。

### 数据表

新增迁移文件：`backend/migrations/000010_create_resource_feedbacks.sql`

- `resource_feedbacks`：存储学生对生成资源的学习效果反馈和下一步建议。

### 前端入口

资源生成结果卡片下方新增“学习反馈”区域，支持直接提交评分、难度、有帮助、完成状态和备注。

## 功能 4：基于画像与反馈的下一步资源推荐

已在资源中心侧栏新增“下一步推荐”能力，系统会综合当前学习画像、最近生成资源和资源反馈，给出下一轮资源包建议。

### 已完成能力

- 根据学习画像中的知识基础、学习目标和资源偏好生成推荐。
- 根据最近资源反馈中的评分、难度和完成情况动态调整推荐理由。
- 支持展示学习效果摘要，便于解释推荐依据。
- 支持一键把推荐资源包填回资源生成表单，形成“生成资源 -> 学习反馈 -> 下一步推荐 -> 再生成”的闭环。

### 后端接口

- `GET /api/resources/recommendations`：获取反馈感知的下一步资源推荐。

### 前端入口

资源中心右侧新增“下一步推荐”面板，展示推荐资源包、推荐理由、推荐资源类型和一键应用按钮。

## 功能 5：资源安全与防幻觉审查

已在 `resourcegen` 模块中新增资源级安全审查能力，用于对生成资源进行可解释的内容安全和防幻觉检查。

### 已完成能力

- 支持对单个生成资源生成安全审查报告。
- 审查维度包括：
  - 事实性与防幻觉
  - 敏感与违规过滤
  - 格式完整性
  - 教学适配性
  - 开源与 AI 工具说明
- 报告包含审查状态、审查分数、风险提示和审查建议。
- 导出的资源包会自动附带每个资源的安全审查摘要，便于提交材料或答辩展示。

### 后端接口

- `GET /api/resources/:resourceId/safety-report`：获取单个资源的安全与防幻觉审查报告。

### 前端入口

资源生成结果卡片新增“安全审查”按钮，点击后展示 `SafetyReviewerAgent` 的审查结果。

## 功能 6：资源包 Markdown 导出

已新增按任务导出完整资源包的能力，用于整理比赛文档、演示材料和提交附件。

### 已完成能力

- 支持按资源生成任务导出 Markdown。
- 导出内容包含：
  - 任务基本信息
  - 多智能体协作记录
  - 资源目录
  - 全部生成资源正文
  - 每个资源的安全审查摘要
- 导出文件名包含任务 ID，便于归档和版本管理。

### 后端接口

- `GET /api/resources/jobs/:jobId/export`：导出某个资源生成任务的 Markdown 资源包。

### 前端入口

资源生成任务进度区新增“导出 Markdown”按钮，点击后在页面内展示可复制的完整 Markdown 内容。

## 功能 7：演示 PPT 大纲生成

已新增按资源生成任务生成答辩 PPT 大纲的能力，用于快速整理初赛演示 PPT 和答辩讲稿。

### 已完成能力

- 支持基于当前资源生成任务自动生成 6 页左右的演示大纲。
- 每页包含：
  - 页面标题
  - 页面要点
  - 讲稿提示
  - 视觉建议
- 大纲覆盖赛题背景、学生画像、智能体协作流程、资源成果、安全反馈闭环和创新价值。
- 可直接作为 PPT 制作提纲或演示视频脚本骨架。

### 后端接口

- `GET /api/resources/jobs/:jobId/presentation-outline`：生成某个资源任务的演示 PPT 大纲。

### 前端入口

资源生成任务进度区新增“生成 PPT 大纲”按钮，点击后展示每页 PPT 的标题、要点、讲稿提示和视觉建议。

## 功能 8：随学随新的画像时间线

已新增学习事件与画像刷新闭环，用于证明学生画像不是一次性表单，而是会根据学习行为持续更新。

### 已完成能力

- 新增 `learning_events` 表，记录资源生成、资源浏览、资源反馈、练习答题等行为信号。
- `POST /api/profile/refresh` 已升级为真实刷新逻辑，会根据近期学习行为更新画像维度。
- 支持根据资源完成记录更新“学习进度”。
- 支持根据偏难反馈、低评分和答题错误更新“易错点偏好”。
- 支持根据近期使用的资源类型更新“资源偏好”和“认知风格”。
- 新增 `GET /api/profile/timeline`，展示画像版本历史与近期行为信号。

### 前端入口

资源中心左侧新增“随学刷新”按钮和“画像更新时间线”区域，展示每次画像变化的摘要、来源和时间。

## 功能 9：资源推送流与学习路径联动

已新增个性化资源推送能力，把生成资源绑定到学生学习路径和今日学习流。

### 已完成能力

- 新增 `resource_push_items` 表，记录资源与知识点、课程、学习阶段、推荐理由、优先级的绑定关系。
- 资源生成完成后自动进入学生资源推送流。
- 新增 `GET /api/resources/feed`，返回当前学生的路径资源推送。
- 仪表盘“资源学习效果”优先展示推送流中的下一步资源。
- 资源中心右侧新增“路径资源推送”面板。
- 知识点详情页的资源卡片可直接进入资源详情页。

## 功能 10：多模态可信交付中心

已新增独立资源详情页，用于展示多模态资源、依据来源、安全审查和学习反馈。

### 已完成能力

- 新增前端路由 `/resources/:resourceId`。
- 支持 Markdown、Mermaid 思维导图、代码块等资源正文展示。
- 视频/动画脚本会额外生成“多模态分镜预览”卡片。
- 资源详情页展示依据来源：知识点、课程、生成智能体、个性化依据、任务编号、安全机制。
- 页面打开会记录 `resource_viewed` 学习事件。
- 支持在详情页提交评分、难度、有帮助、完成状态和备注反馈。
- 新增 `docs/competition/ai-tools-and-licenses.md`，说明 AI 工具、开源协议、科大讯飞辅助工具、内容安全和隐私边界。

## 功能 11：推送资源状态闭环

已增强资源反馈与推送流之间的状态联动。

### 已完成能力

- 学生提交资源反馈后，系统会自动更新对应 `resource_push_items` 的状态。
- 勾选“已完成学习”时，资源推送项变为 `completed`。
- 低评分、无帮助或偏难反馈会标记为 `needs_review`。
- 普通学习反馈会标记为 `in_progress`。
- 资源中心和仪表盘的推送流会展示对应行动文案，如“已完成”“需调整”“继续学习”。

## 功能 12：7 分钟演示脚本生成

已新增围绕单次资源生成任务的比赛演示脚本导出能力。

### 已完成能力

- 新增 `GET /api/resources/jobs/:jobId/demo-script`。
- 自动生成 7 段演示场景，覆盖赛题痛点、画像、智能体生成、多模态可信资源、路径推送、反馈闭环和工程可靠性。
- 每段包含时间范围、操作动作、讲稿和答辩证据点。
- 资源中心任务进度区新增“生成演示脚本”按钮，可与 PPT 大纲、Markdown 资源包配套使用。

## 当前实现边界

本轮实现的是可演示、可持久化的 MVP 闭环。当前画像抽取和资源生成采用规则推理与模板生成方式，已经具备比赛演示中的功能路径。后续若继续增强，可接入 DeepSeek/大模型真实生成、多轮追问补全画像、异步任务队列、流式生成进度、资源质量评分与学生反馈闭环。
