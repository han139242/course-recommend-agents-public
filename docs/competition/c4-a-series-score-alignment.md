# C4 网络技术挑战赛 A 系列评分对齐说明

## 项目名称

突破课程边界的人工智能专业知识点推荐智能体系统

## 评分标准映射

依据 2026 年“中国高校计算机大赛-网络技术挑战赛”竞赛规程，A 系列作品在挑战赛阶段按创意、技术、应用、设计、效果五项评分，每项 20%；选拔赛阶段重点提高技术与设计权重。项目答辩时应按评分项组织材料和演示顺序。

| 评分项 | 项目对应能力 | 答辩展示重点 |
| --- | --- | --- |
| 创意 | 跨课程知识边界的 AI 学习推荐智能体 | 不是普通课程表或问答系统，而是把知识图谱、学习画像、路径推荐、练习反馈和 AI 助教合成学习闭环 |
| 技术 | Go 模块化后端、Vue 3 前端、Neo4j 图谱、Redis 缓存、MySQL 学习数据、AI 流式问答 | 展示后端模块结构、图谱关系查询、统一推荐路径、健康检查、自动化测试 |
| 应用 | 面向学生真实学习任务：找课程、看知识点、沿路径学、做练习、问助教、看进度 | 按首页、知识点详情、学习总览的顺序连续演示 |
| 设计 | 暗色学习工作台、知识地图、进度看板、移动端适配、评委展示中心 | 展示固定入口、清晰导航、无横向溢出、移动端截图 |
| 效果 | 一键启动、可复现运行、可验证服务状态、测试通过、构建通过 | 展示 `scripts/start-demo.ps1`、`/healthz`、`/readyz`、测试和构建结果 |

## 5 分钟答辩演示口径

1. 打开 `http://127.0.0.1:8080/showcase`，说明项目如何对齐 A 系列评分标准。
2. 进入首页知识地图，展示跨课程知识点、先修关系和学习提示。
3. 点击一个知识点，展示前置知识、典型场景、练习测验、推荐路径、学习笔记和 AI 助教。
4. 打开学习总览，展示总体掌握度、待巩固知识点、本周节奏和下一步学习建议。
5. 说明工程可靠性：一键启动脚本、Docker 依赖、后端健康检查、前端测试和生产构建。

## 当前工程证据

- 前端测试：13 个测试文件、49 个用例通过。
- 生产构建：`npm run build` 通过，构建产物输出到 `backend/web/dist`。
- 演示脚本：`scripts/start-demo.ps1` 可一键启动 Docker 依赖、构建前端并启动 Go 后端。
- 固定入口：开发演示统一访问 `http://127.0.0.1:8080/showcase`。

## 高分答辩强调句

本作品的核心不是把 AI 接到聊天框里，而是把“知识结构、学习行为、推荐路径和即时反馈”组合成可运行、可验证、可迭代的专业学习智能体系统。
